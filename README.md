Pradinė nuosavo hash'o idėja:

1. Pasirinksime kokį nors pradinį seed'a
2. Atskirsime inputą į byte'us
3. Pagal tam tikrą tvarką išmaišysime juos
4. Einant iš eilės, lyginsime bitus iš pradinio hash'o ir bitus iš sumaišyto input'o (Konjunkcija arba griežtoji disjunkcija, reikės patestuoti)
5. Tą bitą iš seed'o pakeisime naujuoju gautu iš loginės operacijos
(Optional) 6. Dar kartelį išmaiyšti gautą hash'ą
